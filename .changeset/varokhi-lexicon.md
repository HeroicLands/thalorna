**The Varokhi tongue** — The language note publishes what a Varokhi name is made
of: the elements a kindred names itself from, each traced to the clan names it is
read from, and the rules that join them into a given name, a clan name, a place
name, a rank and an office.

**A woman's name and a man's** — Varokhi marks the difference with a single final
vowel and nowhere else, which is why Rethil and Rethila are one name twice.

**Varokhi names lose their length marks** — The tongue marks no vowel long, so
twenty-nine people of the Vrystwald are written the way a reader would type them:
Hrodar Arnthul, Thaldra Druthgar, Vithar Hildvith.
