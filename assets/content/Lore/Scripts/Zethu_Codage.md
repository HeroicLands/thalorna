Zethu Codage writes the signs of [[skill-khelthzscrpt|Khelathi-zethu Script]] by their ids, in the manner of the Manuel de Codage. A passage marked with `map=zethu-mdc` and no `lang=` is converted sign by sign, so a foreign name, a formula or anything else the [[skill-khelathlng|Khelathi Language]] lexicon does not hold is written exactly as the scribe chooses. The signs are grouped into quadrats and cartouches by the face itself, from the format controls the notation types.

```text
::: {font=khelathi-zethu-glyphs map=zethu-mdc}
11-001:11-002-<13-002\*13-003-12-005:16-027>
:::
```

## The notation

| Typed                  | Writes                                                          |
| ---------------------- | --------------------------------------------------------------- |
| A sign id, as `08-001` | that sign                                                       |
| `-`                    | nothing: it separates one quadrat from the next                 |
| `:`                    | the vertical joiner: what is before it stands over what follows |
| `*`                    | the horizontal joiner: what is before it stands to the right    |
| `(` and `)`            | a segment, a group that stands as one item                      |
| `<` and `>`            | a cartouche, the cord oval round a royal name                   |
| `[ts]` and `[bs]`      | the next sign set in the core's top or bottom right corner      |
| `[te]` and `[be]`      | the next sign set in the core's top or bottom left corner       |
| A space                | the gutter between two signs                                    |

An insertion binds tightest, then the horizontal joiner, then the vertical joiner. Inside a passage `*` is written `\*`, because a pair of bare stars is emphasis.

A sign the face does not draw has no row, so its id passes through as written and is reported where it stands.
